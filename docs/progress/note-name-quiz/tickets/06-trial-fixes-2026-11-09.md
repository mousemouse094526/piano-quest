## Acceptance criteria

### คนที่เปิดครั้งแรก
- F3: ผู้เล่นใหม่อยากรู้ว่าเกมนี้เล่นยังไงและ `time` `count` `zen` ต่างกันอย่างไร → บนหน้า Game เห็นคำอธิบายสั้นภาษาไทยว่าแต่ละ Mode จบเมื่อไร ความยาวเป็นวินาทีหรือจำนวนข้อ และกดปุ่มบนคีย์บอร์ดตามป้ายเล็กใต้ปุ่มได้ ; แถบล่างไม่ใช้คำว่า "Mode bar" (e2e)

### ตอบผิด
- F6: น้องตอบ "ที" ผิดในรอบ `time` → สัญญาณผิดผูกกับข้อที่เพิ่งตอบ ไม่ทำให้ Prompt ใหม่ ("มี") ดูเหมือนตอบผิดไปแล้ว (e2e)
- F9: เจเล่น `mixed` โจทย์ "G" แล้วกด `G` (ชุดผิด) → เห็นชัดโดยไม่ต้องจ้องป้ายเล็กว่าข้อนี้ต้องกดเลข 1–7 ยังไม่นับผิดตาม D20 (e2e)

### คีย์บอร์ดและมือถือ
- F8: เจกด `Shift+Tab` เปลี่ยนค่าใน Mode bar แล้วอยากพิมพ์ตอบต่อ → บนจอบอกว่ากด `Esc` เพื่อกลับเข้าเกม ขณะ focus อยู่ใน Mode bar (e2e)
- F5: ต้นเล่นบน iPhone 390 px ด้วยนิ้วโป้ง → ไม่เห็นป้าย `Tab` `Shift+Tab` `Esc` ในแถบล่างและบนปุ่ม "เล่นอีกรอบ" ; ปุ่มตอบสูงพอให้แตะด้วยนิ้วโป้งโดยไม่พลาดไปข้อถัดไป และ 7 ปุ่มยังอยู่แถวเดียวที่ 375 px (e2e)
