# 05: Dialog ตั้งปุ่มลัด

**What to build:** ผู้เล่นกดปุ่ม "ปุ่มลัด" ใน Mode bar เปิด Dialog เลือก Answer แล้วกดปุ่มบนคีย์บอร์ดที่อยากใช้ ปุ่มที่ชนกันสลับให้เอง คืนค่าเริ่มต้นได้ ทุกการเปลี่ยนอยู่ใน URL ทันทีและเริ่มรอบใหม่ ปิด Dialog แล้วตอบด้วยปุ่มใหม่ได้เลย

**Blocked by:** 04: Keymap ใน URL + ป้ายบนปุ่มคำตอบ

**Covers:**
- Decisions: D33, D35, D36, D37, D39, D40
- Screens: Keymap dialog
- Seams: 2
- User stories: 9, 11

**Status:** ready-for-agent

## Acceptance criteria

### ผูกปุ่ม
- แถว โด รอปุ่ม กด `Q` → URL `solfege-keys` เป็น `Q234567` ปุ่มคำตอบ โด ขึ้น `Q` ; refresh → ยังเป็น `Q` (e2e)
- แถว C รอปุ่ม กด `D` → C เป็น `D` และ D เป็น `C` มีข้อความ "สลับกับ D" (e2e)
- แถว C รอปุ่ม กด `1` → สลับข้ามชุดกับ โด
- แถวรอปุ่ม กด `Enter` → "ใช้ปุ่มนี้ไม่ได้" ยังรอต่อ (e2e)
- "คืนค่าเริ่มต้น" → URL เป็น `CDEFGAB` กับ `1234567` (e2e)
- ตั้ง Keymap กลางรอบ `count` → รอบเริ่มใหม่ (e2e)
- รอบ `time` เดินอยู่ เปิด Dialog แล้วปิดโดยไม่เปลี่ยน → รอบใหม่สถานะ `ready` (e2e)
- คลิกแถวใน Dialog ด้วยเมาส์ → แถวรอปุ่มและรับปุ่มถัดไปได้

### ปุ่มของเกมขณะ Dialog เปิด
- Dialog เปิด กดปุ่มคำตอบ → ไม่ตอบ รอบยัง `ready` (e2e)
- `zen` แถวรอปุ่ม กด `Esc` → เลิกรอ Dialog ยังเปิด ; `Esc` อีกครั้ง → Dialog ปิด รอบไม่จบ (e2e)
- ปิด Dialog แล้วกด `G` ทันที → ตอบได้ (focus กลับพื้นที่เกม) (e2e)

### จอ
- Mode bar มีปุ่ม `Keyboard` ข้างปุ่มเสียง ยังอยู่บรรทัดเดียวที่ 1024 px และตัดบรรทัดเรียบร้อยที่ 375 px
- Dialog ใช้ได้ด้วยคีย์บอร์ดล้วน (`Tab` ระหว่างแถว Enter เริ่มรอปุ่ม)
- มือถือ: แตะแถวแล้วแตะซ้ำหรือปิด Dialog → เลิกรอ มีบรรทัด "ต้องใช้คีย์บอร์ดจริง แตะปุ่มคำตอบได้เสมอ"
