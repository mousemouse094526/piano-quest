# จากแหล่งภายนอกเอาได้แค่ความคิด ลำดับบทเรียน และข้อเท็จจริง

เนื้อหาจากเว็บสอนดนตรีฟรีและจากเกมอื่น (เช่น Monkeytype) เอามาได้แค่ความคิด ลำดับบทเรียน และข้อเท็จจริงทางดนตรี ข้อความเขียนเองทั้งหมด ส่วนรูป ภาพโน้ต เสียง และ font ต้องสร้างเองหรือมี license เปิด เพราะลิขสิทธิ์ไทยไม่คุ้มครองความคิดแต่คุ้มครองการแสดงออก และ repo นี้เป็น public ข้อนี้ตั้งอยู่บนสมมติฐานว่าเว็บไม่มีรายได้และไม่มีโฆษณา
