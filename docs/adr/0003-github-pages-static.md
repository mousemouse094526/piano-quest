# เว็บ static บน GitHub Pages จาก public repo

Piano Quest เป็นไฟล์ static ล้วน deploy ขึ้น GitHub Pages ด้วย GitHub Actions จาก public repo `mousemouse094526/piano-quest` ใต้ path `/piano-quest/` เพราะฟรีและไม่ต้องมีบัญชีที่อื่น อะไรก็ตามที่ต้องใช้ server หรือ repo แบบ private ต้องย้ายที่ host และเขียน ADR ใหม่
