# ปุ่มบนจอเกมไม่รับ focus และทุกปุ่มต้องมีปุ่มลัด

ปุ่มบนหน้าเกมและหน้า Results (นอก Mode bar) ไม่รับ focus ทั้งจาก `Tab` และคลิก เพื่อให้คีย์บอร์ดพิมพ์ตอบได้ตลอดและ `Tab` เริ่มรอบใหม่เสมอแบบ Monkeytype เพราะคนใช้คีย์บอร์ดล้วนจึงไปถึงปุ่มเหล่านี้ด้วย `Tab` ไม่ได้ ทุกปุ่มที่ทำงานได้ต้องมีปุ่มลัดที่อ่านจาก `KeyboardEvent.code` พร้อมป้ายบอกบนจอ ปุ่มใหม่ที่ไม่มีปุ่มลัดต้องอยู่ใน Mode bar หรือเปิดเรื่องนี้ใหม่ด้วย ADR
