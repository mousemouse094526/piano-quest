# ค่าตั้งเกมอยู่ใน URL search params

ค่าตั้งเกมเก็บใน search params ของ URL เท่านั้น ค่าผิดหรือไม่มีจะใช้ค่าเริ่มต้นโดยไม่แสดง error เพราะผู้ใช้อยาก bookmark mode ที่ชอบได้ และ URL ไม่ถือเป็นที่เก็บข้อมูลของแอป (ADR-0001) ชื่อและค่าของ param เป็นสัญญากับ bookmark ของผู้ใช้ จะเปลี่ยนชื่อต้องมี fallback จากชื่อเดิม
