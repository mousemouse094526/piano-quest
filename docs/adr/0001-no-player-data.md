# ไม่เก็บข้อมูลผู้เล่น

ทุกเกมใน Piano Quest ไม่มี server บัญชี `localStorage` `sessionStorage` IndexedDB cookie หรือ analytics ปิด tab แล้วไม่เหลืออะไร เพราะผู้ใช้ต้องการมินิเกมที่เข้ามาเล่นอย่างเดียว และการไม่เก็บข้อมูลส่วนบุคคลทำให้ไม่ต้องมีเรื่อง PDPA เลย ถ้าจะเพิ่มสถิติหรือคะแนนดีสุดในภายหลัง ต้องตรวจ legal ใหม่และเขียน ADR ใหม่มาแทนข้อนี้
