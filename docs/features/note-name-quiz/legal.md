# Legal check: note-name-quiz

**Jurisdiction:** Thailand — checked 2026-11-07 ; ข้อ 3 ตรวจซ้ำ 2026-11-09

- แอปไม่มี server ของตัวเอง GitHub เป็นผู้ให้บริการ host และเป็นผู้ควบคุม log ของตัวเอง ไม่ใช่ของโปรเจกต์นี้
- เว็บไม่หารายได้ ไม่มีโฆษณา

## 1. เอาลำดับบทเรียนและข้อเท็จจริงทางดนตรีจากคู่มือฟรีบนเน็ตมาทำเป็นมินิเกม (D12, D13)

**Verdict: CONDITIONAL**

**Required to be allowed:**
- เอามาแค่ความคิด ลำดับบทเรียน และข้อเท็จจริง (ชื่อโน้ต ความถี่) ซึ่งลิขสิทธิ์ไม่คุ้มครอง [1][2]
- ข้อความ คำอธิบาย และคำสั่งในเกมเขียนเองทั้งหมด ไม่คัดลอกจากเว็บต้นทาง [1]
- ไม่นำรูป ภาพโน้ต ไฟล์เสียง หรือ font จากเว็บต้นทางมาใช้ ใช้ของที่สร้างเองหรือมี license เปิด [1]

## 2. ทำหน้าตาและการเล่นแนว Monkeytype (D1)

**Verdict: CONDITIONAL**

**Required to be allowed:**
- เอาแค่แนวการเล่น (แถบตั้งค่า ปุ่มลัด หน้าผลลัพธ์) ซึ่งเป็นความคิดและวิธีการ [1][2]
- ไม่ใช้ชื่อ โลโก้ ชุดสี หรือ code ของ Monkeytype [1]

## 3. ไม่เก็บข้อมูลผู้เล่น ไม่มีบัญชี storage cookie analytics (D4, D16, D34)

**Verdict: ALLOWED** [3]

- ตรวจซ้ำ 2026-11-09 สำหรับ Keymap: ปุ่มที่ผูกอยู่ใน URL ที่ผู้เล่นถือเอง แอปไม่ส่งไปไหนและไม่เก็บ และระบุตัวบุคคลไม่ได้ [3]
- Dialog รับปุ่มเฉพาะตอนผู้เล่นกดแถวให้รอปุ่ม และอ่านแค่ `code` ของปุ่มเดียว ไม่บันทึกการพิมพ์ [3]
