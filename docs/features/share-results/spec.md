# Spec: share-results

**Status:** draft (ยังไม่วางแผน — เริ่มด้วย `/warroom share-results`)

## Problem

จบ Round แล้ว Player อยากเล่าให้คนอื่นดูว่าตัวเองทำได้แค่ไหน แต่ Piano Quest **ไม่เก็บอะไรไว้เลย** (ADR 0001) จึงไม่มีหน้าโปรไฟล์ ไม่มีคะแนนสะสม และไม่มีอะไรให้ลิงก์ไปดู

มาจาก **user trial 2026-11-09 (F2)**: persona ครูเปียโนอยากส่งผลการเล่นให้ผู้ปกครองทาง LINE แต่ทำไม่ได้ ตัวเลือกที่มีในแอปตอนนี้คืออ่านผลบนจอตัวเอง และคัดลอก URL ค่าตั้ง (ไม่ใช่ผล)

## สิ่งที่ต้องตัดสินก่อนเขียนโค้ด

1. **ส่งอะไร** — สรุปข้อความ (ข้อถูก/ทั้งหมด, เวลา, รายการที่ตอบผิด) หรือลิงก์ที่เปิดแล้วเห็นผล
2. **เก็บที่ไหน** — ถ้าเป็นลิงก์ ต้องมีที่เก็บข้อมูลซึ่งขัดกับ ADR 0001 ถ้าเป็นข้อความล้วนก็เลี่ยงได้ (แนวเดียวกับที่ risk-summary ของ SKOPIA เลือกคัดลอกข้อความ ไม่ทำลิงก์แชร์)
3. **ข้อมูลส่วนตัว** — ชื่อ Player ไม่มีอยู่ในระบบ (ไม่มีบัญชี) · ต้องไม่มีอะไรระบุตัวคนในสิ่งที่แชร์
4. **มือถือ** — ใช้ share sheet ของเครื่อง (แนวทางเดียวกับ risk-summary) หรือคัดลอกข้อความ
