# Sketch: Share text

ตัวอย่าง Share text ที่ D4 และ D7 ตกลงไว้ ใช้ดูหน้าตา ไม่ใช่ code

## `count` 10 ไทย ผิด 2 ข้อ ใช้เวลา 15 วินาที

```text
Piano Quest — ผลรอบนี้
count 10 ข้อ · โด→C · ไทย

ถูก 8
ผิด 2
ความแม่น 80%
โน้ตต่อนาที 32
เวลาเฉลี่ยต่อข้อ 1.50 วินาที

ข้อที่ผิด (โจทย์ / ตอบ / ที่ถูก)
ซอล / A / G
ที / C / B

เล่นค่าเดียวกัน: https://mousemouse094526.github.io/piano-quest/#/?mode=count&len=10&dir=solfege-to-letter&script=th&sound=off
```

## `zen` ตอบถูกข้อเดียว

```text
Piano Quest — ผลรอบนี้
{roundLabel ของ zen mixed en}

ถูก 1
ผิด 0
ความแม่น 100%
โน้ตต่อนาที —
เวลาเฉลี่ยต่อข้อ —

ไม่ผิดสักข้อ

เล่นค่าเดียวกัน: {URL ของหน้า}
```

## ผิดเกิน 20 ข้อ

```text
ข้อที่ผิด (โจทย์ / ตอบ / ที่ถูก)
{20 แถวแรกตามลำดับที่ตอบ}
และอีก 7 ข้อ
```

## กติกา

- บรรทัดที่สองคือสิ่งที่ `roundLabel()` คืนในตอนสร้าง ซึ่ง note-name-quiz ticket 06 (F14) จะเปลี่ยนป้าย Direction ตาม Script ตัวอย่าง `zen` จึงเว้นไว้
- ตัวเลขใช้ค่าสุดท้ายของ `results()` รูปแบบเดียวกับบนจอ
- ป้ายเวลาเฉลี่ยเขียน `วินาที` ท้ายตัวเลข ไม่ใช่ในวงเล็บแบบบนจอ เพราะอ่านเป็นประโยคใน LINE
- แถวข้อที่ผิดเรียงตามลำดับที่ตอบ แสดงไม่เกิน 20 แถว (D7)
- ลิงก์คือ `window.location.href` ตอนกด ซึ่งเป็นรูป `#/?…` ตาม ADR-0004 และ note-name-quiz D27 ; test ส่ง URL คงที่เข้าไป
