# Vite React web

A static single-page app of music-theory mini games, deployed to GitHub
Pages. Every game is a feature folder; game rules live in a pure engine.

## Folder structure

```
src/
├── main.tsx                 ← createRouter with createHashHistory, mounts app
├── routes/
│   ├── __root.tsx           ← root route: layout shell
│   └── _public/             ← every page is public (no accounts, ADR-0001)
│       └── index.tsx        ← "/" route, validateSearch for its params
├── features/[feature]/
│   ├── engine/              ← pure TS reducer + data + rng, co-located *.test.ts
│   ├── components/          ← UI for this feature
│   ├── hooks/               ← React glue: key listener, ticker, engine state
│   └── sound/               ← Web Audio helpers (only if the feature has sound)
├── components/
│   ├── ui/                  ← shadcn/ui primitives (generated by the shadcn CLI)
│   └── common/              ← app components 2+ features use
├── hooks/                   ← hooks 2+ features use
└── lib/                     ← non-React helpers (shadcn `cn`)
e2e/                         ← Playwright specs, one file per user flow
```

## Flow

route (reads search params) → feature component → feature hook → engine reducer.
Sound is a side effect the hook fires after the engine state updates.

## Where shared code goes

- Code one feature uses lives in that feature.
- A second user appears → move it to the central folder named for its kind
  (see the tree), in the same change. Never create a shared file ahead of
  need.
- Central folders never import from `features/`.

## Never break

- `engine/` imports nothing from React, the DOM, or `window`; time (`now`)
  and randomness (`seed`) arrive as event data (ADR-0005).
- No `localStorage`, `sessionStorage`, IndexedDB, cookies, or analytics
  anywhere (ADR-0001).
- Search params are read only through the route's `validateSearch`, which
  falls back to defaults on bad values (ADR-0002).
- Router uses `createHashHistory`; never browser history (ADR-0004).
- No copied text, images, audio, or fonts from outside sources; assets are
  self-made or openly licensed (ADR-0006).
- Icons come from `lucide-react` only.
